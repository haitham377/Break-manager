# Activity Picker CLI

A lightweight CLI tool to help you reclaim your free time, step away from mindless doomscrolling, and engage in intentional, fulfilling breaks. 

Instead of reaching for cheap dopamine when taking a break, this tool randomly picks a curated activity based on whether you want something screen-free or educational.

## Prerequisites

* Python 3.6+

## Setup & Usage

1. Clone the repository:
   ```bash
   git clone [https://github.com/your-username/your-repo-name.git](https://github.com/your-username/your-repo-name.git)
   cd your-repo-name
   ```
2. Run the script:

```Bash
python main.py
```
3. Follow the terminal prompts:
- Option 1: Filter and pick a random break activity.

- Option 2: Add a new activity to your list.

## Data Storage
Your activities are stored locally in data.json, which is automatically created on your first run.
